# GitHub User Fetch Project

This is a simple JavaScript project that fetches GitHub user data from the GitHub API and displays user profile cards with image, username, and profile link.

## 🚀 Features

* Fetch data using **Fetch API**
* Use **async / await**
* Handle errors with **try...catch**
* Dynamically create user cards
* Show profile image
* Show username
* Clickable GitHub profile link

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* GitHub API

project-folder/

## 🔗 API Used

GitHub Users API:

```text
https://api.github.com/users
```

## ▶️ How to Run

1. Clone the repository
2. Open the project folder in VS Code
3. Open `index.html` in browser

## 📸 Output

Displays GitHub users in card format with:

* avatar image
* username
* profile link
